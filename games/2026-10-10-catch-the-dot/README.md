# Catch the Dot

A small reaction game built with plain HTML, CSS, and JavaScript.

## How to play

1. Open `index.html` in a modern web browser.
2. Press **Start game**.
3. Click the red dot whenever it appears in a new position.
4. Score as many points as possible before the 30-second timer reaches zero.
5. Select **Play again** to try for a better score.

## Rules

- Each successful click on the dot gives **1 point**.
- The dot moves to a random location after each click.
- The round lasts **30 seconds**.
- Your best score is saved in this browser using local storage.
- No libraries, installs, or internet connection are required after the files are available.

## Files

- `index.html` — game layout and accessible controls.
- `style.css` — responsive styling and play area.
- `game.js` — score, timer, dot movement, and best-score logic.

## Controls

Mouse or touch: tap/click the red dot.
