# Whack-a-Mole: Garden Rush

Tap moles in a 30-second round. Regular moles earn 1 point; rare golden moles earn 3. Tapping an empty hole loses 1 point, down to zero. Use Start game to begin or restart, and Reset best to clear the browser-saved record. Mouse, touch, and keyboard buttons are supported. Open index.html in a modern browser; no installation or external dependencies are required.
