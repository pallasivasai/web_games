# Memory Match

A tiny browser game made with plain HTML, CSS, and JavaScript.

## How to play
1. Open  in a modern browser.
2. Read the on-screen instructions.
3. Press **Start game** and follow the prompts.

## Rules
Memorize the four symbols shown, then click the tiles in the exact sequence. A wrong tile ends the round. Match all four to win.

## Files
-  — page and controls.
-  — responsive styling.
-  — game behaviour.
-  — instructions and rules.

No packages or build steps are needed.
