# Pattern Pulse — Simon Sequence

Pattern Pulse is a lightweight sequence-memory game made with plain HTML, CSS, and JavaScript. Open `index.html` in any modern browser; no installation or internet connection is required.

## Objective

Repeat the colored-light sequence in the exact order shown. Each successful round adds one more light to the sequence. See how many levels you can complete.

## Rules

1. Press **Start game**.
2. Watch the four colored pads light up in sequence.
3. Repeat the sequence by clicking or tapping the same pads in the same order.
4. Each completed sequence advances you to the next level and adds one new light.
5. One incorrect selection ends the run. Choose **Play again** to start over.
6. Your best completed level is saved in your browser when local storage is available.

## Controls

- **Mouse/touch:** Click or tap the colored pads.
- **Keyboard:** Press `1` for red, `2` for green, `3` for blue, or `4` for yellow.
- **Replay sequence:** During your turn, select **Replay sequence** to watch the current pattern again.
- **Reset:** Clears the current run and returns to the start screen.

## Accessibility and compatibility

- Responsive layout for desktop and mobile screens.
- Buttons have accessible labels and visible keyboard focus.
- Game status is announced through a live region.
- Reduced-motion preferences are respected.
- No frameworks, external assets, APIs, or build step are required.
