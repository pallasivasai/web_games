# Word Scramble Sprint

A quick vocabulary puzzle built with plain HTML, CSS, and JavaScript. No libraries or installation are required.

## How to play

1. Open `index.html` in any modern browser.
2. Select **Start game**.
3. Rearrange the displayed letters mentally, type the original word, and press **Enter** or **Check word**.
4. Solve as many words as you can before the 60-second timer reaches zero.
5. Use **Skip** if you're stuck, then keep going.

## Rules

- Each correct word earns **2 points**.
- Skipping a word costs **1 point**; the score cannot go below zero.
- Incorrect guesses do not cost points, so keep trying.
- The round lasts **60 seconds**.
- Words are case-insensitive.
- Select **Play again** after the round to reset the score and timer.

## Controls

- Keyboard: type your answer and press **Enter** to check it.
- Mouse or touch: use the on-screen buttons.

## Files

- `index.html` — game layout, responsive styles, and game logic.
