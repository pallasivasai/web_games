# Maze Escape

A small, randomly generated maze game built with plain HTML, CSS, and JavaScript. Open `index.html` in any modern browser—no installation, build step, or network connection is needed.

## Objective

Reach the golden exit (🚪) from the blue starting position before the 90-second timer expires.

## Rules

1. Press **Start maze** to begin the 90-second run.
2. Move through open paths; green walls block movement.
3. Each successful move increases your step count. Trying to walk into a wall does not use a step.
4. Reach the exit at the bottom-right of the maze to win.
5. If the timer reaches zero first, the run ends.
6. Your fastest escape time is saved in your browser when local storage is available.

Every new maze is generated by a randomized depth-first search that carves a connected route, so the exit is reachable.

## Controls

- **Keyboard:** Arrow keys or **W A S D**.
- **Mobile:** Use the on-screen directional buttons.
- **Restart run:** Return to the start of the same maze and reset the timer and step count.
- **New maze:** Generate a different maze and return to the ready state.

## Accessibility and compatibility

- Responsive layout with touch-friendly controls.
- Direction buttons have accessible labels and visible keyboard focus.
- Status updates are announced through a live region.
- Uses only built-in browser APIs; no external assets or dependencies.

## File

- `index.html` — maze generation, rendering, controls, timer, and best-time storage.
